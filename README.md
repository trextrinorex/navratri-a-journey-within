# Navratri — A Journey Within

An immersive, cinematic, browser-based Navratri storytelling experience.

## Experience

- 7-chapter cinematic story flow
- Three.js-powered atmospheric 3D environment
- Animated divine scene, temple lights, moon, stars, embers and diyas
- Aarohi-led narrative
- Interactive Navadurga exploration
- Symbolic story of Maa Durga and Mahishasura
- Inner-meaning chapter connecting the festival to courage and light
- Garba celebration finale
- Ambient Web Audio soundscape and optional browser narration
- Responsive mobile/desktop layout
- No build step or npm installation required

## Run locally

Open `index.html` in a modern browser. For camera/audio-like browser features, use a secure origin such as GitHub Pages or a local development server.

## GitHub Pages

This is a static site. GitHub Pages can publish the repository directly from the `main` branch using `/` as the source.

## Design direction

The experience is inspired by the supplied Navratri cinematic reference: deep midnight blues, vermilion, antique gold, Indian architectural motifs, diya illumination, elegant serif typography and story-first composition. It intentionally turns those visual ideas into an interactive animated web experience rather than a conventional festival information page.

## Cultural note

The story and symbolism are presented as an educational/cultural experience. Different regions and traditions observe Navratri in different ways, so future versions can add regional perspectives and sources.
